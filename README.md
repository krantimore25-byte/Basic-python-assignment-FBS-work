# Basic Python Assignment

This repository contains basic Python programming assignments created to practice core programming concepts. The exercises cover fundamental topics such as variables, data types, operators, conditional statements, loops, functions, lists, tuples, dictionaries, sets, and file handling.

## Objectives

* Learn Python syntax and programming basics
* Improve problem-solving skills
* Practice writing clean and readable code
* Build a strong foundation in Python programming

## Topics Covered

* Variables and Data Types
* Input and Output
* Operators
* Conditional Statements (`if`, `elif`, `else`)
* Loops (`for`, `while`)
* Functions
* Lists, Tuples, Dictionaries, and Sets
* String Manipulation
* File Handling
* Exception Handling

## How to Run

1. Clone this repository.
2. Open the project in your preferred Python IDE or code editor.
3. Run the required Python (`.py`) file using:

   ```bash
   python filename.py
   ```

## Purpose

This repository is intended for learning, practice, and improving Python programming skills through simple assignments and exercises.
